# SHI HAN GAME Portfolio

从主作品墙复制出的独立游戏方向版本，保持相同的视觉与交互，并增加数值拆解案展示。

## 本地预览

在 `portfolio-game` 目录运行任一静态服务器，例如：

```powershell
python -m http.server 4173
```

访问 `http://localhost:4173/`。

## 发布前需要替换

1. 元素回廊和弈者使用正式展示截图，数值拆解案使用用户提供的示例截图。
2. 两个游戏入口、Controller 仓库与数值拆解案飞书链接均已填写。
3. 后续可以继续增加游戏项目或拆解案例，保持相同的作品区块结构即可。

## GitHub Pages

该目录作为独立仓库发布，避免影响原作品墙；所有站内资源均使用相对路径，可部署到 GitHub Pages 的项目子路径。
