# SHI HAN GAME Portfolio

独立的游戏方向作品集。首页直接进入作品，采用简约漫画分镜风格：暖白纸面、朱红编号、黑色细框、对话气泡与出框角色。无个人理念宣言首屏。

## 本地预览

在 `game-version` 目录运行任一静态服务器，例如：

```powershell
python -m http.server 4173
```

访问 `http://localhost:4173/`。

## 首页内容与维护

1. `index.html`：项目文案、实机截图、机制示例及原生折叠数值笔记。元素项目沿用现有名称「元素回廊」。
2. `home.css` 为基础排版，`sketch.css` 提供角色布局与精灵动画，`comic.css` 为已选定的漫画视觉层。首页默认漫画版，`?theme=sketch` / `?theme=atlas` 保留探索方向预览；`design-options/` 中的截图为当时的探索稿。
3. `home.js`：猫咪原始→火→水三种真实形态的循环交互，也支持直接点击形态按钮。猫素材来自用户指定的 `C:/Users/78566/Documents/ChatGPT/元素地牢-godot版/assets/characters/cat/`，每套为 8 帧 idle、8 fps（1 秒循环）；使用透明裁切横排图保留帧对齐，并以 4 倍整数像素显示。支持暂停、离屏暂停、减少动态效果和键盘操作。关闭 JavaScript 时显示静态猫与正文介绍，笔记仍可展开。
4. 土元素建筑与其他元素的反应为迭代方向，用正文说明；弈者的跨体系遗物、卡牌指挥及大招均按已实现机制介绍。已删除元素反应交互面板、反击等级示例与大招流程图。
5. 四位角色宁不凡、赤炎、炎术士、千机为静态透明 WebP 立绘，源素材、尺寸和裁切记录见 `assets/characters/MANIFEST.md`。
6. 两个游戏入口、Controller 仓库与数值拆解案飞书链接沿用原有地址。旧详情页继续使用原有 `styles.css` 和 `script.js`。

## 验证

首页在 320、375、667（横屏）、768、1024、1440 像素宽度下检查折叠和展开状态，无整页横向溢出；验证猫咪三种真实形态循环与直接选择、真实动画帧、暂停/播放、键盘操作、图片加载、页面锚点、减少动态效果及禁用 JavaScript 的降级内容。资源和浏览器脚本检查无错误。

## GitHub Pages

该目录作为独立仓库发布，避免影响原作品墙；所有站内资源均使用相对路径，可部署到 GitHub Pages 的项目子路径。

操作提示位于元素回廊实机画面下方：Shift 冲刺、E 切换元素形态、1/2/3 对应技能、空格跳跃。在线体验按钮默认朱红色；火、水形态按钮具有对应图形和一次性短动效，支持减少动态效果设置。
